# Göktuğ İşeri — Cybernetic Engineering Portfolio 🚀

Modern, yüksek performanslı ve Awwwards seviyesinde tasarlanmış **Göktuğ İşeri** portfolyo web uygulaması.

![Portfolio Banner](public/images/neuro-shield.jpg)

## 🌟 Öne Çıkan Özellikler

- **Canlı İnteraktif Algoritma Laboratuvarı**:
  - **Shannon Entropisi ($H(X)$) & PII Maskeleme**: Gerçek zamanlı matematiksel entropi analizi, OWASP LLM01 prompt injection ve NVI Mod 10 TCKN filtreleme simülasyonu.
  - **SynapseFlow Kahn DAG Yürütücüsü**: $O(V+E)$ karmaşıklığında topolojik sıralama ve DFS tabanlı döngü (cycle) koruması.
  - **AuraCipher LSB Kripto Modülü**: AES-256-GCM yüklerinin RGB piksellerinin en anlamsız bitlerine enjekte edilmesi.
- **3D Kart Eğimi (Tilt) & Işık Yansıması (Specular Glare)**: İmleç hareketine göre dinamik fizik motoru.
- **Synthesized Web Audio API**: Harici dosya indirmeden saf ses frekanslarıyla dokunsal (tactile) ses geri bildirimi (Açılabilir / Kapatılabilir).
- **İnteraktif Cyberpunk CLI Terminali**: `~` kısayolu veya butonla açılan retro-hacker terminali (`bio`, `projects`, `skills`, `sudo hire`, `clear`).
- **Gerçek Proje Görselleri**: NeuroShield, SynapseFlow, AuraCipher, Han Kebap Steakhouse, PlanPilot ve DietitianApp projelerinden yüksek çözünürlüklü görseller.
- **Derinlemesine İnceleme Modalı (Deep Dive Drawer)**: Matematiksel formüller, sistem mimari diyagramları ve kaynak kod kesitleri.

## 🛠️ Teknoloji Yığını

- **React 19**
- **TypeScript 5.x**
- **Tailwind CSS 4**
- **Vite 8**
- **Lucide Icons**
- **Web Audio API**
- **Canvas Particle Synapse Engine**

## 💻 Kurulum & Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev

# Üretim sürümünü derleyin
npm run build
```

Uygulama varsayılan olarak `http://localhost:5173` adresinde çalışır.
